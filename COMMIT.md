# Commit Message Generation Rules

Please follow these guidelines when generating commit messages:

- **Language:** Always write commit messages in English.
- **Structure:** Always provide a title and a description.
- **Title format:** The title must be short and objective, summarizing the main change. If there are many changes, focus on the primary one.
- **No periods:** Do not use a period (.) at the end of the title.
- **Conventional Commits:** Follow the Conventional Commits pattern (e.g., `feat:`, `fix:`, `chore:, CI:, docker:, doc:, refactor:`).
- **Description format:** The description should be a bulleted list detailing each change made, separated by `-`.
- **Categorization:** If possible, group the items in the description by category (e.g., Features, Fixes, Chores).
